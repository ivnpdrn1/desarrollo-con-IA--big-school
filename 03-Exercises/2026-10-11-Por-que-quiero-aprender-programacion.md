# Ejercicio recomendado — ¿Por qué quiero aprender a programar?

**Fecha:** 2026-10-11  
**Programa:** Desarrollo con IA — Big School  
**Tipo:** reflexión aplicada a experiencia real

## 1. Respuesta principal

Quiero aprender a programar para pasar de **tener ideas, definir productos y dirigir a la IA** a poder **comprender, construir, revisar, depurar y evolucionar directamente los sistemas que convierten esas ideas en productos reales**.

Mi objetivo no es convertirme únicamente en alguien que escribe código. Quiero desarrollar la suficiente profundidad técnica para actuar como **AI Software Engineer y arquitecto de soluciones**, entendiendo lo que ocurre debajo de los prompts, tomando mejores decisiones técnicas y reduciendo la dependencia de terceros o de resultados de IA que no pueda validar.

Los proyectos que ya he desarrollado muestran que mi interés está en resolver problemas completos: negocio → datos → software → IA → cloud → operación. Por eso necesito programación como lenguaje de construcción y como herramienta de criterio técnico.

## 3. Áreas de programación que más me atraen

### A. AI Software Engineering — área principal
Construcción de aplicaciones en las que la IA es parte del producto, no un accesorio.

**Me interesa porque:** conecta todos mis proyectos y combina programación, APIs, datos, agentes, pruebas y producto.

### B. Backend, APIs y lógica de negocio
Servicios que reciben datos, aplican reglas, consultan bases de datos y coordinan otros sistemas.

**Aplicaciones directas:** MarketMirrorAI, Gas Station Operations y AI Health Agent CRM.

### C. Agentes, herramientas y Harness
Sistemas de IA capaces de usar herramientas bajo reglas, contexto, permisos, memoria, evaluación y supervisión humana.

**Aplicaciones directas:** mi flujo ChatGPT → especificación → Claude Code, automatización con n8n y futuros sistemas multiagente.

### D. Cloud y DevOps
Desplegar software de forma segura, observable, repetible y económicamente sostenible.

**Aplicación directa:** AWS, Nubelai, MarketMirrorAI y mis proyectos productivos.

### E. Desarrollo web full-stack
Construcción de interfaces y experiencias completas conectadas al backend.

**Aplicaciones directas:** byDebut, Gas Station Operations y CRM.

### F. Edge AI y visión artificial
Procesamiento inteligente cerca del dispositivo físico.

**Aplicación directa:** JetImage y potenciales interfaces inteligentes en estaciones de servicio.

## 6. Orden recomendado de aprendizaje

### Etapa 1 — Fundamentos y lectura de código
**Python + Git + terminal + estructuras de datos + funciones + control de flujo + errores + pruebas.**

Meta: poder leer un programa pequeño, explicar cada parte y modificarlo sin depender de copiar instrucciones.

### Etapa 2 — Backend y datos
**FastAPI + HTTP/REST + JSON + SQL + PostgreSQL/Supabase + pytest.**

Meta: construir una API pequeña conectada a una base de datos y probarla.

### Etapa 3 — Aplicaciones web
**TypeScript + React + Next.js.**

Meta: conectar una interfaz real con una API y persistencia.

### Etapa 4 — IA, agentes y automatización
**APIs de modelos + herramientas + MCP + n8n + evaluación + permisos + observabilidad.**

Meta: crear un agente limitado y verificable que use herramientas sin autonomía irrestricta.

### Etapa 5 — Producción en AWS
**IAM + networking + compute + almacenamiento + observabilidad + despliegue.**

Meta: desplegar una aplicación pequeña con seguridad, métricas y rollback.

### Etapa 6 — Especialización Edge AI
**OpenCV + PyTorch/TensorRT + Jetson.**

Meta: implementar un prototipo medible solo cuando JetImage vuelva a ser el laboratorio activo.
