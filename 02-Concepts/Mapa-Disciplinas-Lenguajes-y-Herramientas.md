# Mapa de disciplinas y herramientas

Ver [Lección: elegir mi camino](../01-Class-Notes/2026-10-10-Caminos-en-Programacion.md).

**Objetivo:** AI Software Engineering, cruzando aplicaciones web, backend, IA agéntica, automatización y cloud.

```text
Problema de negocio
  ↓
Interfaz (React / Next.js, TypeScript)
  ↓
API y lógica de negocio (Python / FastAPI o TypeScript)
  ↔ Datos (PostgreSQL / Supabase)
  ↔ Automatización (n8n) y Agentes / Harness
  ↓
Infraestructura y operaciones (AWS, IAM, GitHub, pruebas, observabilidad)
```

La secuencia es conceptual: no todas las soluciones utilizan todas las capas ni ejecutan sus interacciones linealmente.

## Elección razonada
1. Especificar problema y resultados.
2. Revisar tecnologías existentes del proyecto.
3. Comparar alternativas por productividad, seguridad, mantenimiento, rendimiento y costo.
4. Implementar un prototipo pequeño y medir.
5. Documentar la decisión y sus consecuencias.

Python: prioridad pedagógica inicial. TypeScript: segundo lenguaje, particularmente para aplicaciones web. El resto se aprende según la necesidad.
