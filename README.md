# Desarrollo con IA — Big School

Repositorio de aprendizaje y desarrollo práctico asociado al proyecto **Desarrollo con IA - Big School**.

## Objetivo
Organizar las clases, los conceptos, los ejercicios, los agentes de IA y los prompts de trabajo, conectando la formación con proyectos reales.

## Organización

- `00-Project-Overview/`: objetivos, ruta de aprendizaje y decisiones.
- `01-Class-Notes/`: apuntes por clase.
- `02-Concepts/`: explicaciones y relaciones conceptuales.
- `03-Exercises/`: prácticas, soluciones y aprendizajes.
- `04-Agents-and-Harness/`: agentes, `AGENTS.md`, herramientas, reglas y orquestación.
- `05-Prompts/`: prompts versionados para ejecución con herramientas como Claude Code.
- `99-Progress-Log/`: avances y próximos pasos.

## Método de trabajo

1. Se define y clarifica el objetivo con ChatGPT.
2. Se documentan conceptos, decisiones y prompts en este repositorio.
3. Se implementa y prueba con las herramientas de desarrollo correspondientes.
4. Se registran hallazgos y ajustes con trazabilidad en GitHub.

> Este repositorio no sincroniza automáticamente el historial del chat. Sus contenidos se actualizan mediante acciones explícitas de lectura y escritura.
